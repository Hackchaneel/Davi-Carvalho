## 🚀 Projeto em destaque

### 📦 Sistema de Estoque Profissional

Sistema desenvolvido com o objetivo de fornecer uma solução completa para **gerenciamento de estoque empresarial**.

O projeto envolve diferentes áreas do desenvolvimento de software, desde a construção da API e modelagem do banco de dados até o gerenciamento de usuários e movimentações de estoque.

#### 🔧 Principais funcionalidades

* 🔐 Sistema de autenticação
* 👥 Gerenciamento de funcionários
* 🏢 Gerenciamento de empresas
* 📦 Cadastro e gerenciamento de produtos
* 🏷️ Gerenciamento de categorias
* 🚚 Gerenciamento de fornecedores
* 📥 Registro de entrada de produtos
* 📤 Registro de saída de produtos
* ⚠️ Controle de estoque mínimo
* 🔔 Sistema de alertas
* 🗄️ Integração com PostgreSQL
* 🔌 API REST
* 🧱 Arquitetura organizada entre diferentes responsabilidades
